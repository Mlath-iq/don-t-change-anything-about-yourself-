موقع "إيلان، أحبج على طبيعتج"
=================================

1- افتح ملف index.html بمتصفح Chrome أو Edge.
2- الموقع كامل بملف واحد، ولا يحتاج صور أو ملفات إضافية أو إنترنت.
3- ارفع index.html على GitHub Pages إذا تريد تشاركه ويا إيلان.
4- لتغيير الكلام: افتح index.html ببرنامج VS Code وعدّل النص العربي بين وسوم HTML.
5- لتغيير الألوان: غيّر متغيرات الألوان بقسم :root بأعلى الصفحة.
6- الموقع فيه رسائل تفاعلية ورسالة سرية بنهاية الصفحة.

لا توجد أغنية أو صوت: الموقع مصمم كرسالة هادئة بدون ملفات صوت خارجية.
